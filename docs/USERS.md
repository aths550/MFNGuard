## How the list was compiled

- 79 form responses were received.
- 72 contained an unshielded Preview address; 2 were repeat submissions from the same wallet, leaving **70 unique wallets**.
- Not counted: 2 with no address, 2 Preprod addresses, 1 address that was not a Midnight address, and the 2 shielded addresses above.
- Every counted address starts with `mn_addr_preview1` and is a well-formed bech32m string of the same length.
- The form did not collect transaction hashes, so per-wallet activity should be checked against the contract address above using the explorer or indexer above.
